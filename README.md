# Express + PUG + EJS Demo

Демонстраційний Express-сервер, який інтегрує два шаблонізатори одночасно:

- **PUG** — для маршрутів, пов'язаних із користувачами (`/users`, `/users/:userId`);
- **EJS** — для маршрутів, пов'язаних зі статтями (`/articles`, `/articles/:articleId`).

## Встановлення та запуск

1. Клонуйте репозиторій:
   ```bash
   git clone <URL репозиторію>
   cd express-pug-ejs-demo
   ```

2. Встановіть залежності:
   ```bash
   npm install
   ```

3. Запустіть сервер:
   ```bash
   npm start
   ```
   або в режимі розробки з автоперезапуском (потрібен `nodemon`):
   ```bash
   npm run dev
   ```

4. Відкрийте у браузері:
   ```
   http://localhost:3000
   ```

   Порт можна змінити через змінну середовища `PORT`:
   ```bash
   PORT=4000 npm start
   ```

## Опис маршрутів

| Маршрут                | Метод | Шаблонізатор | Опис                                                                 |
|-------------------------|-------|--------------|-----------------------------------------------------------------------|
| `/`                      | GET   | —            | Головна сторінка з посиланнями на `/users` та `/articles`.            |
| `/users`                 | GET   | PUG          | Список усіх користувачів у вигляді карток.                            |
| `/users/:userId`         | GET   | PUG          | Детальна інформація про конкретного користувача (email, роль, дата реєстрації, біографія). Якщо користувача з таким `id` не існує — повертається 404 та список користувачів з повідомленням про помилку. |
| `/articles`              | GET   | EJS          | Список усіх статей у вигляді карток (заголовок, автор, дата, короткий опис). |
| `/articles/:articleId`   | GET   | EJS          | Повний текст конкретної статті. Якщо статтю з таким `id` не знайдено — повертається 404 та список статей з повідомленням про помилку. |
| `*` (будь-який інший)    | GET   | —            | Сторінка 404 "Сторінку не знайдено".                                  |
